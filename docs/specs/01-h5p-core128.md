## 3. The ten content types

The minimum versions come from the development plan. Session 1 must confirm them against the
seed packages and update this table with the exact installed versions.

| # | Display name (nn) | Machine name | Min. version | Why it is in the set | Main universal design guardrail |
|---|---|---|---|---|---|
| 1 | Presentasjon | `H5P.CoursePresentation` | 1.27 | Self-paced concept slides with embedded checks | One concept per slide; real headings; no layout tables |
| 2 | Interaktiv video | `H5P.InteractiveVideo` | 1.28 | Segmented lecture video with retrieval checks | WebVTT captions; keyboard-operable controls |
| 3 | Spørsmålssett | `H5P.QuestionSet` | 1.21 | Focused retrieval practice | Elaborated feedback; no timers |
| 4 | Interaktiv bok | `H5P.InteractiveBook` | 1.12 | Multi-chapter modules with resume | Chapter navigation; bounded chapter length |
| 5 | Kolonne | `H5P.Column` | 1.19 | 2–3 focused activities on one page | At most 3 sub-activities |
| 6 | Dra ord | `H5P.DragText` | 1.10 | Text-based categorisation and terminology | Keyboard drop-zone selection |
| 7 | Fleirval | `H5P.MultiChoice` | 1.16 | Concept checks with diagnostic distractors | Option-specific feedback |
| 8 | Fyll inn manglande ord | `H5P.Blanks` | 1.14 | Recall of terms, units, dosages, syntax | Unambiguous prompts around input fields |
| 9 | Biletmarkørar | `H5P.ImageHotspots` | 1.10 | Guided visual walkthroughs | Numbered, ordered hotspots; alt text |
| 10 | Forgreiningsscenario | `H5P.BranchingScenario` | 1.9 | Case-based professional judgement | 3–4 decision points; retry paths; never colour-only paths |

**Deliberately excluded:** `H5P.DragQuestion` (free 2-D drag and drop). It is a significant barrier
for keyboard, switch and screen-reader users (D-006). Sub-libraries such as `H5P.TrueFalse`,
`H5P.SingleChoiceSet`, `H5P.DialogCards`, `H5P.Accordion`, `H5P.AdvancedText`, `H5P.Image` and
`H5P.Video` stay installed as **dependencies** and may be used *inside* containers. They are not
offered as top-level choices. *DragQuestion is not offered as a sub-content choice either*: this
is enforced with `alterLibrarySemantics` on container libraries (see `H5P-002`).

Nynorsk display names are drafts and must be checked against H5P's own `nn` language files and by
HVL's language advisers.

## 4. Requirements — H5P engine

#### H5P-001 · MUST · S1 · Target Core API 1.28 and the new Hub
`H5pConfigFactory` sets `coreApiVersion = { major: 1, minor: 28 }`,
`hubContentTypesEndpoint = 'https://hub-api.h5p.org/v1/content-types/'` and
`hubRegistrationEndpoint = 'https://hub-api.h5p.org/v1/sites'`, plus the F1/F2 workarounds above
(`getLocalIdOverride`, pre-set `uuid`). Core client files come from the release tag `1.28.0`. The
editor has no 1.28 release, so its files come from one reviewed, pinned commit with recorded hashes
(D-022). The project never tracks a moving branch such as `master`.
- **Acceptance:** On startup the server logs the core version and Hub host. It refuses to start if
  the core client files on disk report a different version than the config. No code contains the
  string `api.h5p.org/v1/content-types` except the test that asserts its absence.
- **Verify:** Unit test of the factory; boot test (`h5pServerInit`).

#### H5P-002 · MUST · S2 · Ten-type authoring whitelist
`HvlTop10ContentTypeFilter` makes only the ten machine names in §3 appear as creatable in the editor
Hub list. Their dependencies remain installable. `H5P.DragQuestion` is removed from the options of
every container's sub-content selector (via `alterLibrarySemantics`).
- **Acceptance:** (a) The content-type-cache AJAX response contains exactly the ten machine names as
  creatable. (b) Saving content whose main library is not in the list returns HTTP 403 with a
  translated error. (c) No container semantics offer `H5P.DragQuestion`. (d) The whitelist is one
  constant, `HVL_TOP10_CONTENT_TYPES`, with a comment linking here.
- **Verify:** Unit tests for (a)–(c); test names start with `[H5P-002]`.

#### H5P-003 · MUST · S2 · Deterministic offline seeding
`npm run seed:libraries` installs the ten types and their dependencies from verified `.h5p` packages
in `docs/reference/h5p-core-1.28-seed-packages/` (see [reference README](../reference/README.md)).
It needs no network access. A `SHA256SUMS` file lists the hash of each package. The script refuses
to install a package whose hash does not match.
- **Acceptance:** Running the script twice is idempotent. CI seeds from scratch in under 2 minutes.
- **Verify:** Integration test against an empty storage.

#### H5P-004 · MUST · S1 · Production storage adapters
| Interface | Implementation | Backing store |
|---|---|---|
| `IContentStorage` | `PrismaContentStorage` | PostgreSQL (metadata, parameters) + S3 (files) |
| `ILibraryStorage` | File-system-backed on a shared volume, wrapped in Lumi's `CachedLibraryStorage` (D-026) | Shared volume; S3 only if S6 needs it |
| `ITemporaryFileStorage` | `S3TemporaryFileStorage` | S3 with a lifecycle rule as a backstop |
| `IKeyValueStorage` | `RedisKeyValueStorage` | Redis (shared across nodes) |
| `ILockProvider` | `@lumieducation/h5p-redis-lock` | Redis |
| `IContentUserDataStorage` | `PrismaContentUserDataStorage` | PostgreSQL |

`TemporaryFileCleanupJob` calls `h5pEditor.temporaryFileManager.cleanUp()` every 5 minutes. A Redis
lock ensures only one node runs it.
- **Acceptance:** Two server instances share the content-type cache and locks. The temporary file
  cleanup runs once per interval cluster-wide.
- **Verify:** Integration tests against PostgreSQL, Redis and an S3-compatible store (D-023). The
  user-data adapter is built and tested with `H5P-005` in S2 (D-028).

#### H5P-005 · MUST · S2 · Learner state persistence (resume)
`PrismaContentUserDataStorage` stores H5P user data keyed by
`(contentId, subContentId, dataType, learnerKey, contextId)`. `learnerKey` is the pseudonym defined
in `DATA-002`, never a raw ID. `contentUserStateSaveInterval` stays at the default 5 s.
"Invalidate on content change" follows H5P semantics, with the author confirmation in `PROD-013`.
- **Acceptance:** After a simulated reload, the player receives the saved state. A learner in a
  different Canvas course (context) gets separate state.
- **Verify:** Integration test.

#### H5P-006 · MUST · S2 · Permission system
`HvlPermissionSystem` implements `IPermissionSystem` with this matrix. Anything not listed is denied.

| Permission | learner | author | admin |
|---|---|---|---|
| `GeneralPermission.InstallRecommended` | ✗ | ✗ | ✓ |
| `GeneralPermission.UpdateAndInstallLibraries` | ✗ | ✗ | ✓ |
| `GeneralPermission.CreateRestricted` | ✗ | ✗ | ✓ |
| `ContentPermission.Create` / `List` | ✗ | ✓ | ✓ |
| `ContentPermission.View` | if published **and** visible to them (`PROD-006`) or launched via LTI | owner, co-author, visible, or published and launched by them via LTI (course copy, D-060) | ✓ |
| `ContentPermission.Edit` / `Delete` / `Download` | ✗ | owner or co-author | ✓ |
| `UserDataPermission.*` on **own** data | ✓ | ✓ | ✓ |
| `UserDataPermission.*` on **someone else's** data | ✗ | ✗ (aggregates only via insight) | for data-subject requests only, audit-logged |
| `TemporaryFilePermission.*` | ✗ | own files | ✓ |

Leaving `permissionSystem` undefined (Lumi's `LaissezFairePermissionSystem`) is forbidden. A boot check enforces this.
- **Verify:** A table-driven unit test covers every cell above.

#### H5P-007 · MUST · S3 · Authenticated H5P AJAX in iframes
`HvlUrlGenerator` extends Lumi's `UrlGenerator`. Every AJAX, user-data and set-finished URL carries the
ltik (Canvas mode) or a CSRF token (portal mode), URL-encoded, as specified in `LTI-003`. *Amended in S3
(D-058):* the token is added by our class rather than Lumi's `queryParamGenerator`, which does not encode it
consistently; content files use signed URLs (`/h5p/files/<grant>/…`) instead of a token.
- **Acceptance:** A request to an H5P AJAX endpoint without a valid token returns 401.
- **Verify:** Integration test for each mode.

#### H5P-008 · MUST · S2 · Nynorsk-first translation
`HvlTranslationCallback` uses i18next with `fallbackLng: ['nb', 'en']` and default `lng: 'nn'`. When a
content-type library has no `language/nn.json`, the library's `nb` and then `en` strings are used.
- **Acceptance:** A library without `nn` renders in `nb`. The UI language can be switched per user.
- **Verify:** Unit test with a fixture library.

#### H5P-009 · MUST · S4 · Inject theme and client scripts into player and editor
Use `customization.global.styles` and `customization.global.scripts`, or `alterLibraryFiles`, to add
`packages/hvl-h5p-theme/dist/hvl-h5p-theme.css` (`UD-011`) and the xAPI bridge script (`LTI-010`)
inside the H5P iframe.
- **Acceptance:** The iframe document contains both assets with integrity hashes and `nonce`s that match the CSP.
- **Verify:** Playwright test inspects the iframe DOM.

#### H5P-010 · SHOULD · S6 · Panopto-first video guidance
Use `alterLibrarySemantics` on `H5P.InteractiveVideo` and `H5P.Video` to replace the upload field's
description with nn/nb/en guidance. It recommends HVL's Panopto streaming URL with a `.vtt` caption
track, and allows direct `.mp4` uploads only up to 50 MB (enforced in `SEC-005`).
- **Verify:** Unit test on the altered semantics.

#### H5P-011 · MUST · S2 · Controlled library updates
Libraries are installed or updated only by admins, through the seed script or the admin UI. Each
change writes an audit event: actor, library, old version, new version and source hash. In
production, *install from Hub on demand* is disabled. Updates first go to staging.
- **Verify:** Integration test; audit log assertion.

## 5. Requirements — upload and content security

#### SEC-001 · MUST · S2 · Sanitise SVG files (CVE-2025-7062 mitigation)
Register `SvgSanitizer` in `fileSanitizers` for both editor uploads **and** `.h5p` package imports.
It wraps `@lumieducation/h5p-svg-sanitizer` (DOMPurify) and additionally rejects or strips:
`<!DOCTYPE>` and `<!ENTITY>` declarations (XXE and "billion laughs"), `<script>`, `on*` attributes,
`<foreignObject>`, `javascript:` and `data:text/html` URLs, and external `href`/`xlink:href` references.
- **Acceptance:** A corpus of malicious SVGs in `apps/server/test/fixtures/svg/` comes out inert. It
  includes `standalone="no"` with an external entity, an inline script, an event handler and a
  foreignObject with HTML. Benign SVGs keep their appearance (snapshot of the rendered PNG).
- **Verify:** Unit tests `[SEC-001] …`; one integration test per upload path.

#### SEC-002 · MUST · S2 · Narrow allowlist and content sniffing
The content file allowlist (`contentWhitelist`) is narrowed to what the ten types need:
`json png jpg jpeg gif webp svg webm mp4 mp3 m4a ogg wav vtt webvtt pdf txt csv docx xlsx pptx odt ods odp`.
`xml`, `swf`, `md`, `textile`, `diff` and `patch` are removed. `FileTypeSniffer` rejects a file whose
magic bytes contradict its extension, for example HTML in a `.png`.
- **Verify:** Unit tests with polyglot fixtures.

#### SEC-003 · MUST · S2 · Uploaded packages never install code for non-admins
When an author imports a `.h5p` file, the server installs **only the content**. A library in the
package that is not already installed, or that has a different patch version, is rejected with a
clear message. Admins can install it after review.
- **Verify:** Integration test with a package that contains a modified `H5P.MultiChoice`.

#### SEC-004 · MUST · S2 · Serve user content defensively
Content files are served with `X-Content-Type-Options: nosniff`. SVG and document files are served
with `Content-Security-Policy: sandbox; default-src 'none'; style-src 'unsafe-inline'`. Non-media
types are served with `Content-Disposition: attachment`. In production, content files are served from
a **separate origin** (e.g. `files.interaktiv.hvl.no`), so a script in a file cannot reach the app's
origin, cookies or ltik.
- **Verify:** Integration test of headers; deployment checklist item.

#### SEC-005 · MUST · S1 · Size limits and archive safety
`maxFileSize` is 50 MB and `maxTotalSize` is 200 MB per package. The server rejects zip entries with
path traversal or absolute paths. Package imports are processed in a temporary directory with a quota.
- **Verify:** Unit tests with a zip-slip fixture and an oversize fixture.

#### SEC-006 · SHOULD · S6 · Malware scanning
When `CLAMAV_HOST` is configured, register `@lumieducation/h5p-clamav-scanner` in `malwareScanners`.
- **Verify:** Integration test with the EICAR test string (skipped when ClamAV is absent).

#### SEC-007 · MUST · S1 · Dependency hygiene
All runtime dependencies are pinned exactly (no `^`) and listed in `package-lock.json`. CI runs
`npm audit --omit=dev --audit-level=high` and fails on unreviewed findings. A reviewed exception must
be recorded in `DECISIONS.md` with an expiry date. Renovate (or Dependabot) opens update PRs weekly.
- **Verify:** CI job.

#### SEC-008 · MUST · S2 · Regression test for CVE-2025-47828
A test saves content with `<img src=x onerror=alert(1)>` in a plain-text field. It asserts that the
stored and rendered value is escaped.
- **Verify:** `[SEC-008]` unit test.
