## 1. How to read it

- **"H5P as it comes"** is what one gets by installing the software and changing nothing. An integrator can configure
  much of it. Several things this service does (its own permission system, file sanitiser and virus scanner) use
  places the library offers for exactly that; the library only leaves them empty. A row says what the default is,
  not what is possible.
- **"Adds" is not "is safe".** The last column of each row says what limits the claim, and §3 lists where the
  service is not better, or is more limited, than the software it builds on.
- **The service does more with learners' data than the bare software does.** The server library keeps a learner's
  saved progress and nothing else. This service also keeps learning events, for the teacher's insight and the
  formative score to Canvas. Rows 7 to 11 are about how that is limited. They are not a claim that less is processed.
- Paths that start with `src/` are under `apps/server/src/`; `test/`, `e2e/` and `a11y/` are under `apps/server/`.
  `LUMI/` is `node_modules/@lumieducation/h5p-server/build/src/`, `CORE/` is `apps/server/h5p/core/js/` (fetched by
  `npm run h5p:fetch-core`). `D-nnn` is a decision in [docs/DECISIONS.md](../DECISIONS.md), `R` with a number a
  residual in the DPIA input §12, "limitation n" an item of [docs/EVALUATOR-GUIDE.md](../EVALUATOR-GUIDE.md) §6.

## 3. Where HVL Interaktiv is not better, or is more limited

- **It collects more than the bare software.** The server library keeps saved progress only. This service also keeps
  learning events. That is a new processing of personal data, with the limits in rows 7 to 11, and it waits for
  the data protection officer: residuals R1 to R43 in the DPIA input are open.
- **It carries H5P's code and the upstream flaw.** Everything H5P's content types do in a learner's browser, they do
  here too, on the application's own address, unread line by line. CVE-2025-7062 is defended around, not removed.
- **It allows more files than the upstream defaults.** SVG files are allowed, where the library's default list has
  none. One file may be 50 MB and one activity 200 MB, against the library's 16 MB and 64 MB
  (`LUMI/implementation/H5PConfig.js:72-73`, `src/h5p/H5pConfigFactory.ts`).
- **It offers fewer content types:** ten.
- **The same as upstream:** scores are worked out in the browser, so a learner can forge them (formative use only);
  usage statistics are off; progress is saved every five seconds; inline styles are allowed.
- **Nobody outside the build has checked it.** The code, the tests and this paper were written by one AI, and no
  person has reviewed the code or tried to break in ([human-review.md](human-review.md)). Canvas and Feide are mocks
  in every test. The other items of [docs/EVALUATOR-GUIDE.md](../EVALUATOR-GUIDE.md) §6 apply as well.

## 4. H5P.com and other hosted services: not verified by us

This paper says nothing about H5P.com, or about H5P as a plug-in in Moodle or WordPress. We have not inspected any
of them and cannot: a hosted service is known by its contract and its configuration, not by code we can read. The
hosted service may well do some of the things in §2 itself. Whoever compares HVL Interaktiv with a hosted service
needs that service's own answers to, at least:

1. What is stored about a student (name, e-mail address, answers, times), where, and for how long?
2. What can a teacher see about one student?
3. Who are the sub-processors, and in which countries is the data stored and handled?
4. How are uploaded files checked and served?
5. Which security reviews or certifications does the service have, and when were they done?
6. How is a student's request for access or erasure handled?

HVL's data processing agreement and the service's own documentation answer these; the answers belong in this section,
with their source and date, written by the person who read them.

## 5. What would make this paper stronger

A person who reads the rows against the code ([human-review.md](human-review.md) lists where to start), a security
test by someone who did not build the service, a run against HVL's real Canvas and Feide, and the data protection
officer's decisions on the residuals.
