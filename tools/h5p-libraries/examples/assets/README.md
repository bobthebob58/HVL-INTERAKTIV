# Example assets

Media files the example activities in `../` use. They are our own (no third-party material), made on
2026-10-23 with Chromium through Playwright:

| File | What it shows | How it was made |
|---|---|---|
| `diagram.png` | 960 × 540 diagram "Læringsdesign: før, under og etter samlinga" with three numbered phases | Screenshot of a static HTML page |
| `clip.webm` | 6-second clip (VP8, 640 × 360, no sound) with three Nynorsk sentences | Playwright `recordVideo` of three static pages, 2 s each |
| `clip.nn.vtt` | Nynorsk captions for `clip.webm` | Written by hand |

The colours in the images match the HVL tokens (D-017); they are pixels, not code, so the colour lint does not apply.
